# WorldsTip提示词优化 · 技能概述

> 适用平台：任意支持 `SKILL.md` 的 Agent（SkillHub / DeepSeek Harness / Qoder / Coze）
> 版本：1.0.1 ｜ 许可：MIT ｜ 依赖：无

## 一句话

把随手写的一句话，改写成 AI 能照着执行的提示词——**默认只改写，不替你干活**。

## 它解决什么问题

| 典型痛点 | 具体表现 | 本技能的处理 |
|---|---|---|
| 提示词太糊 | "帮我弄一下那个表" → AI 反复追问 | 补出目标、对象、验收，缺口写成一句问句 |
| 信息被丢掉 | 草稿里的路径、报错、版本号，改写后没了 | 事实零丢失：路径 / 标识符 / 报错原文 / 数字原样保留 |
| 意图跑偏 | 让你改提示词，它直接开工；让你干活，它只回一段 prompt | 先做意图分诊，再决定改写、评估还是执行 |

## 核心能力

1. **意图分诊**：把请求分成「改写 / 评估 / 执行 / 别的任务」四类，附 3 条判定规则（指代对象 → 祈使句 → 冲突时先改写再执行）。
2. **四种模式**：`clarity` 清晰（默认）、`structured` 结构化、`detail` 细化、`brief` 精简——按**下游用途**选，不靠用户猜形容词。
3. **保真改写**：先抄出事实清单（路径、标识符、报错、数字、禁止项），写完逐项比对，缺的补回原位。
4. **不发明**：原文没有的需求、技术栈、字段、验收条件，一律不加；必须用户补的，写成一句问句。
5. **单趟执行**：一次自检、最多一次澄清、不产出多版本让用户挑。

## 怎么用

说一句就行，不需要记命令：

| 你说 | 它做 |
|---|---|
| 帮我优化提示词 / 这句怎么问更清楚 | 输出改写后的提示词正文 |
| 这段 prompt 有什么问题 / 这样问行吗 | 先给 2–3 条问题，再给一版改写 |
| 按结构写 / 分成目标和要求 | 输出「目标 / 上下文 / 要求 / 验收」四段 |
| 写详细点 / 压缩成一句 | 补执行细节，或压到一句任务加三条约束 |
| 帮我写个脚本汇总日报 | **不动提示词**，直接完成任务 |

## 输入输出示例

**示例一（默认清晰模式）**

```text
输入：帮我写个脚本把那个日报表格汇总一下

输出：写一个汇总日报表格的脚本：读取本周的日报文件，按人汇总每天的完成项与阻塞项，
      输出一份可直接发送的汇总表。保留原有列名与字段含义，不要改数据，只做汇总。
```

**示例二（判断为"评估"而不是"改写"）**

```text
输入：我这个 prompt 是不是太长了：你是一个非常专业的助手，请务必认真仔细地思考……

输出：问题：① 前两句是语气铺陈，没有约束力；② 没有给出任务的输入与输出；
      ③ "认真仔细"无法验收。

      用中文回答；不确定就直说，不编造；输出只给结论与依据。
```

## 不做什么

- 不替用户回答提示词本身——输出的是"要做的事"，不是"做完的结果"。
- 不为了显得专业而把一句话扩成八条；`clarity` 的长度基线是原文的 0.8–1.5 倍。
- 不在用户明确要求前换语言、换技术栈、扩大任务范围。
- 不适用：直接完成任务、翻译、润色文案、改代码——这些按原任务处理。

## 包结构与技术特性

```text
worldstip-prompt-polish/
├── SKILL.md              入口：意图分诊 → 模式选择 → 单趟四步 → 自检
└── references/
    ├── modes.md          四种模式的写法细则
    ├── examples.md       6 组改写对照 + 7 种常见失败模式
    ├── rewrite-prompt.md 固定改写指令（与 DSH 插件同源）
    └── dsh-plugin.md     插件形态说明（可选读）
```

- 5 个文件 / 约 16 KB / 零依赖 / 无脚本，不触发脚本类安全扫描。
- 渐进披露：启动只读说明，正文与参考文件按需加载；一次调用最多读 1 个参考文件。
- 无本机绝对路径、无明文密钥、无外链。

## 与插件的关系

同一套规则也做成了 DeepSeek Harness 的输入框按钮插件：点「优化」即改写草稿，或输入 `/polish <文本>`。技能不依赖插件，可单独使用；两处规则同源，改一处需同步另一处。
