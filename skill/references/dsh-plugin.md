# 插件形态（可选）

同一套改写规则也可以装成 DeepSeek Harness 的输入框按钮：点一下，用当前模型把草稿改写成更清晰的提示词并回填。

本技能不依赖插件；下面只是说明两者关系，便于用户按需选择。

## 两种形态对比

| 形态 | 触发方式 | 适用 |
|---|---|---|
| 本技能 | 用户说"优化提示词" | 任意支持 SKILL.md 的 Agent |
| DSH 插件 | 点输入框的「优化」按钮 | 装了 DeepSeek Harness 的桌面端 |

插件由两部分组成：

- Host 半：注册 `/polish` 命令，调用模型流式接口做一次改写，返回改写结果。
- Client 半：在输入框工具行注册一个紧凑按钮，读取草稿、调用命令、把结果写回草稿。

## 插件与技能的差异

- 插件里的改写规则写死在 Host 代码的系统提示词中，用户改不了措辞。
- 本技能把规则写成文档，Agent 会按当前上下文选择模式，也能回答"为什么这么改"。
- 插件每次点按都会在会话里留下一条命令记录；技能不会。

## 安装位置

插件安装到 DSH 的插件目录，用插件管理器安装本地目录即可；技能放到 Agent 的 skills 目录。两者互不影响，可以同时装。
